# Restitution Power BI — Phase 6

Fichier : `Projet_Stage.pbix` (Power BI Desktop). Il s'appuie sur la base PostgreSQL
et les vues de `05_KPI_SQL/`. Les données sont issues de sources ouvertes
(FAOSTAT, Banque mondiale).

## Pages

| Page | Contenu |
|---|---|
| Direction | Production mondiale, produits et pays suivis, évolution 1961-2024, répartition géographique |
| Produits | Rendement moyen par produit, production au Bénin, classement des pays producteurs, cartes Café / Coton / Maïs / Riz |
| Prix | Prix export et import moyens, évolution du prix export (USD/tonne), détail par pays |
| Pays | Comparaison de pays, production régionale, indicateurs macroéconomiques, carte |

## Utilisation

Ouvrir le fichier dans Power BI Desktop. Pour actualiser les données, renseigner
la connexion PostgreSQL locale (voir `04_Base_PostgreSQL/`).
